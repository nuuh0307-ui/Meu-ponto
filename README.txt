MEU PONTO — PWA

Arquivos:
- index.html: aplicativo
- manifest.json: configuração de instalação
- sw.js: cache para funcionamento offline
- icon-192.png e icon-512.png: ícones

Publicação gratuita:
1. Crie um repositório GitHub público chamado meu-ponto.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em Settings > Pages, selecione Deploy from a branch, branch main, pasta /(root).
4. Aguarde a URL github.io ficar disponível.
5. Abra a URL no Chrome Android e use Instalar aplicativo / Adicionar à tela inicial.

Os registros ficam no armazenamento local do navegador/aplicativo, não são enviados ao GitHub.
